# Regression Checklist

## ゲームコントローラー全体ゲート（rc4必須）

- [ ] 新規設定では全体スイッチがOFFで起動する
- [ ] Version 9以前の設定を読み込んでも暗黙にONにならない
- [ ] 非表示時はcontroller専用sectionとHold欄がDOMに存在せず、一般管理欄の小さな`実験機能を表示`だけが見える
- [ ] OFF時にJoy-Con／互換HIDの列挙・Open・再接続を行わない
- [ ] OFF時にXInput workerを起動せず、P1～P4をpollしない
- [ ] worker停止直前に届いた遅延HID／XInput eventを無視する
- [ ] OFF時はcontroller入力を含むruleを実行しない
- [ ] `機能を停止して設定画面から隠す`でworkerが停止し、保存済みcontroller rule、Joy-Con設定、manual HID registrationを削除しない
- [ ] OFF→ONで保存済みcontroller ruleと詳細設定が復帰する
- [ ] OFF中もmouse/key rule、short/long press、profile switch、自動切替が動く
- [ ] mouse/key long-press中にcontrollerをOFFにしてもその状態を巻き添えで消さない
- [ ] controller Hold／long-press中にOFFへ切り替えてkeyやpending stateが残らない
- [ ] BetterJoy／JoyToKeyが生成したkeyboard/mouse入力を、controller機能OFFのまま処理できる
- [ ] 診断にglobal gate、Joy-Con worker、XInput workerの状態が表示される

# Windows実機 回帰チェックリスト

## 起動・終了

- [ ] EXE単体で起動する
- [ ] 二重起動で二つ目の常駐プロセスが残らない
- [ ] 二重起動時に既存GUIが開く
- [ ] トレイから終了できる
- [ ] `Ctrl+Alt+Shift+F12`で緊急停止できる
- [ ] スタートアップショートカットから`--tray`起動できる

## 通常入力

- [ ] 左クリック、右クリック、中クリックが割り当て外で正常
- [ ] ドラッグが正常
- [ ] X1/X2単押しが正常
- [ ] ホイール上下が正常
- [ ] Ctrl/Shift/Alt/Winが残留しない
- [ ] 高速連続操作で入力遅延が増えない

## 記録GUI

- [ ] 「入力を記録」が目立ち、押すと記録状態が分かる
- [ ] 全入力を離すと自動終了・自動反映する
- [ ] 「実行内容を記録」も同様に自動終了する
- [ ] 記録を中止できる
- [ ] チェックボックスが実際に操作できる
- [ ] 各保存ボタンの対象が文言で判別できる

## 長押し

- [ ] しきい値より前に離すと短押し時の実行内容だけが1回動く
- [ ] しきい値まで押し続けると長押し時の実行内容だけが1回動く
- [ ] 長押し後に離しても短押し時の実行内容が追加発火しない
- [ ] 「短押し時の実行をキャンセル」で、長押し時は何も実行されない
- [ ] 長押し専用ルール（短押し出力が空）を保存・実行できる
- [ ] 長押し時の実行内容を記録し、全キーを離すと自動保存される
- [ ] 100msと5000msの境界設定が保存される
- [ ] X1長押し中にX1+ホイール等の組み合わせを使っても、X1単体の長押しが後から発火しない
- [ ] 押しっぱなし中にDOWNを再送するマウスでも長押しが二重発火しない
- [ ] 左・右・中クリックを長押し対象にしようとすると、理由が分かるエラーになる

## プロファイル

- [ ] 通常時プロファイルを変更・保存できる
- [ ] 編集対象と適用中が別でも、正しい対象を編集できる
- [ ] 既存の自動切替ルールを選択・編集・保存できる
- [ ] プロセス名だけで自動切替する
- [ ] `.exe`あり/なしの双方で一致する
- [ ] タイトル条件とパス条件がANDとして働く
- [ ] 優先順位1が優先順位2より先に使われる
- [ ] 対象アプリを離れると通常時プロファイルへ戻る
- [ ] 設定画面を開いたままでも直前アプリ判定が維持される
- [ ] 自動切替表示が実際の有効状態と一致する

## Joy-Con（L）／Switch互換Raw HID接続

- [ ] Windows Bluetooth設定でJoy-Con（L）を通常ペアリングできる
- [ ] アプリ起動前から接続済みのJoy-Con（L）を検出する
- [ ] アプリ起動後に接続したJoy-Con（L）を検出する
- [ ] `Joy-Conを接続・再検索`で多重ワーカーを作らず再列挙する
- [ ] 接続状態、製品名、識別情報がGUIと診断に表示される
- [ ] 取得可能な場合はバッテリー残量が表示される
- [ ] Joy-Con電源断を切断として検出する
- [ ] Windows側Bluetooth切断を検出する
- [ ] 切断時にJoy-Con由来の押下キー・修飾キーが残留しない
- [ ] 再接続後に入力が自動復帰する
- [ ] スリープ復帰後に再接続できる
- [ ] Joy-Con未接続でも既存マウス・キーボード機能が起動・動作する
- [ ] 全HID interface（vendor-specificを含む）を列挙し、キーボード／マウス等を誤登録しないための警告が表示される
- [ ] 候補に製品名、manufacturer、VID/PID、serialまたはfingerprint、Usage、入出力report長が表示される
- [ ] 未知VID/PID候補は自動接続されず、一覧から正確なHID interfaceを明示登録した場合だけ開く
- [ ] 明示登録した互換HIDはR/W OpenとNintendo report-mode初期化を試し、拒否時だけread-onlyへfallbackする
- [ ] Steamを完全終了した状態で互換HIDをOpen・Readできる
- [ ] 既知の`0x30`／`0x21`／`0x3f`報告を正しい経路で解析する
- [ ] 7バイトまたは先頭0付き8バイトのinput-only報告を解析する
- [ ] 未知reportをボタン入力へ誤変換せず、長さと先頭hexを診断へ表示する
- [ ] 登録していない非Joy-Con HIDデバイスを誤接続しない

## Joy-Con（L）ボタン

- [ ] 上、下、左、右のDOWN／UPを各1回検出する
- [ ] L、ZL、SL、SRのDOWN／UPを各1回検出する
- [ ] －、キャプチャー、スティック押込みのDOWN／UPを各1回検出する
- [ ] 押しっぱなし中の重複報告で重複DOWNを発生させない
- [ ] 報告欠落後の次状態または切断でUPを補正する
- [ ] `ゲームコントローラー入力を記録`後、全入力を離すと自動確定する
- [ ] 記録中止後に入力が割り当てへ混入しない
- [ ] 単一キーへ変換できる
- [ ] 修飾キー付きショートカットへ変換できる
- [ ] 複数キー同時押しへ変換できる
- [ ] マウスボタンへ変換できる
- [ ] ホイールへ変換できる

## Joy-Con（L）短押し・長押し

- [ ] Joy-Conボタン短押しで短押し出力が1回だけ動く
- [ ] Joy-Conボタン長押しで長押し出力が1回だけ動く
- [ ] Joy-Con長押し後のUPで短押し出力が追加発火しない
- [ ] Joy-Con長押しキャンセルで短押し出力が動かない
- [ ] 長押しタイマーとUPが競合しても二重実行しない
- [ ] 長押し中の切断で出力を追加発火せず状態を破棄する
- [ ] 緊急停止、設定再読込、プロファイル切替、終了時に保留長押しを破棄する

## Joy-Con（L）スティック

- [ ] GUIの現在位置が物理スティック移動へ追従する
- [ ] ニュートラルで方向入力が発生しない
- [ ] デッドゾーン境界の内側でDOWNしない
- [ ] 押下しきい値を超えると1回だけDOWNする
- [ ] 押下後、解放しきい値より内側へ戻るまでUPしない
- [ ] しきい値付近の揺れでDOWN／UPを連打しない
- [ ] 4方向設定では優勢軸だけが入力される
- [ ] 8方向設定では斜め二方向を同時入力できる
- [ ] X軸反転が保存・再読込後も働く
- [ ] Y軸反転が保存・再読込後も働く
- [ ] キャリブレーション開始から中心・可動範囲を保存できる
- [ ] 軽微な中心ドリフトをキャリブレーションで補正できる
- [ ] 無効または不完全なキャリブレーション値を安全な既定値へ正規化する
- [ ] スティック→WASDで斜め移動できる
- [ ] 半倒し／全倒しを実装した版では二段階境界にヒステリシスがある

## XInputコントローラー

- [ ] `xinput1_4.dll`利用可能環境でXInput待機状態になる
- [ ] Xbox系／XInputモードのパッドをP1〜P4として自動検出する
- [ ] A/B/X/Y、LB/RB、Start/Back、左右スティック押込みを各DOWN／UPで検出する
- [ ] LT/RTは押下・解放の別しきい値でチャタリングしない
- [ ] 左右スティックの上下左右は押下・解放の別しきい値でチャタリングしない
- [ ] スティック方向の反転時に旧方向UPが新方向DOWNより先に届く
- [ ] `XInput P1:LB`等の表示文字列を編集・保存・再読込して同じ入力へ戻せる
- [ ] 最大4台を同時接続してスロット別の入力を区別できる
- [ ] 切断またはXInput APIエラー時にDOWN中の全入力へ合成UPが届く
- [ ] XInputのHold中に切断してもキーが残留しない
- [ ] XInput未接続／DLL利用不可でもマウス・キーボード・Joy-Con機能が継続する
- [ ] 物理コントローラーをゲームも直接読む場合の二重入力有無を確認する

- [ ] Joy-Con複合ルール使用後も物理マウスの右クリック・ドラッグが正常
- [ ] Joy-Con単独ルールとJoy-Con＋マウス複合ルールの前置入力競合で単独長押しが後発しない
- [ ] `XInput P1:LB + マウスX1`を一つのルールとして記録・保存・実行できる
- [ ] Joy-ConとXInputの同名相当ボタンが押下状態で衝突しない

## Joy-Conとプロファイル

- [ ] 通常時プロファイルのJoy-Con配置が適用される

## 設定互換性

- [ ] Joy-Conフィールドのない旧`config.json`をそのまま読み込める

- [ ] 不明なJoy-Conボタンコードを読み込んでも既存入力コアが停止しない
- [ ] 破損したJoy-Con設定だけを安全な既定値へ正規化し、他設定を維持する

## Joy-Con負荷・長時間

- [ ] 1時間以上Joy-Con入力を継続して切断・遅延・入力残留がない

- [ ] Redragon等の高イベント量マウスとJoy-Conを併用できる
- [ ] Joy-Conの60Hz報告で低レベルフック遅延が増えない
- [ ] 切断・再接続を20回繰り返してゴルーチン・ハンドルが増え続けない
- [ ] 8時間常駐してJoy-Con未使用時の通常マウス回帰がない

## 長時間

- [ ] 8時間以上常駐して右クリック等が失われない
