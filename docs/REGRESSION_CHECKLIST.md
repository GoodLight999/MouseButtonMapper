# Windows実機 回帰チェックリスト

## 起動・終了

- [ ] EXE単体で起動する
- [ ] 二重起動で二つ目の常駐プロセスが残らない
- [ ] 二重起動時に既存GUIが開く
- [ ] トレイから終了できる
- [ ] `Ctrl+Alt+Shift+F12`で緊急停止できる
- [ ] スタートアップショートカットから`--tray`起動できる

## 通常入力

- [ ] 左クリック、右クリック、中クリックが割り当て外で正常
- [ ] ドラッグが正常
- [ ] X1/X2単押しが正常
- [ ] ホイール上下が正常
- [ ] Ctrl/Shift/Alt/Winが残留しない
- [ ] 高速連続操作で入力遅延が増えない

## 記録GUI

- [ ] 「入力を記録」が目立ち、押すと記録状態が分かる
- [ ] 全入力を離すと自動終了・自動反映する
- [ ] 「実行内容を記録」も同様に自動終了する
- [ ] 記録を中止できる
- [ ] チェックボックスが実際に操作できる
- [ ] 各保存ボタンの対象が文言で判別できる

## プロファイル

- [ ] 通常時プロファイルを変更・保存できる
- [ ] 編集対象と適用中が別でも、正しい対象を編集できる
- [ ] 既存の自動切替ルールを選択・編集・保存できる
- [ ] プロセス名だけで自動切替する
- [ ] `.exe`あり/なしの双方で一致する
- [ ] タイトル条件とパス条件がANDとして働く
- [ ] 優先順位1が優先順位2より先に使われる
- [ ] 対象アプリを離れると通常時プロファイルへ戻る
- [ ] 設定画面を開いたままでも直前アプリ判定が維持される
- [ ] 自動切替表示が実際の有効状態と一致する

## 長時間

- [ ] 8時間以上常駐して右クリック等が失われない
- [ ] Redragon等の高イベント量マウスで継続動作する
- [ ] フック再登録が発生しても自動復帰する
- [ ] ログに大量の`slow hook callback`が連続しない
