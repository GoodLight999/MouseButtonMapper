# Ray Pawn+ (RM-3360LR) 非公式設定ガイド — 公式ソフトがダウンロードできない場合の対処法

> **検索キーワード / Keywords**: Ray Pawn+, Ray Pawn Plus, RM-3360LR, RM3360LR, 公式ソフト ダウンロードできない, 公式クライアント 消滅, サーバー終了, 割り当てソフト, 右サイドボタン PageUp PageDown 変更, DPI 変更, ポーリングレート 1000Hz, LED 消灯 色変更, SINOWEALTH Wired Gaming Mouse, VID 258A PID 1007, FW GM07, PMW3360

ゲーミングマウス **Ray Pawn+（型番: RM-3360LR / 両利き 9 ボタン / PixArt PMW3360 搭載）** は現在も流通していますが、公式の設定クライアントの配布サーバーが閉鎖・消滅しており、公式ツールを入手できなくなっています。

**MouseButtonMapper** には、実機 USB HID 解析に基づいて作成した **SinoWealth / Ray Pawn+ 専用プラグイン** が標準同梱されています。公式ソフトなしで、以下の本体オンボード設定と高度なボタン割り当てをすべて安全に行えます。

---

## このツールでできること（公式ソフト不要）

※ すべての通信仕様は実機解析に加え、公式インストーラー（`PAWN_Setup_V1.0.4.exe` / `Cfg.ini` / `OemDrv.exe`）との照合で 100% 一致を確認済みです。

- **全 9 ボタンのオンボード割り当て書き換え ＆ 本体直書きモード**
  - 初期状態で `PageUp` / `PageDown` に固定されている **右サイドボタン 2 つ** と **DPI+ / DPI- ボタン** を自由に書き換え可能です。
  - **ソフト連携モード（`F13 / F18 / F19 / F20`）** に加え、**プロファイル上のショートカット（例: `Ctrl+A` / `Ctrl+X` / `Win+V` / `Win+H`）をマウス本体メモリへ直接書き込む「本体直書きモード（ハイブリッド / 完全スタンドアロン）」** にも対応しました。本体直書きしたボタンは管理者権限アプリや別 PC でもソフトなしで動作します。
- **論理ボタン名での直感的な割り当て**
  - Ray Pawn+ を接続すると、MouseButtonMapper 上で `左サイド1 / 左サイド2 / 右サイド1 / 右サイド2 / DPI+ボタン / DPI-ボタン` として認識されます。
  - 短押し / 長押し分岐に加え、**押している間ずっと押し続ける Hold モード**（音声入力の Push-to-Talk やゲームのチャージ操作など）にも対応しています。
- **DPI・ポーリングレート変更（オンボード保存）**
  - センサー（PixArt PMW3360）の DPI を `100〜12,000 DPI`（100 刻み）および公式仕様の `24,000 DPI`（補間値）で設定、不要な DPI スロットの無効化（1 段階固定も可能）。
  - ポーリングレートを `125 / 250 / 500 / 1000 Hz` から選択可能（公式アプリ既定では非表示の USB レート切替にも対応）。
- **LED エフェクト全 11 種・輝度 4 段階・単色カラー変更 & アプリごとの自動色切替**
  - `OFF / カラフルストリーミング / 単色点灯 / ブリージング / テイル / ネオン / カラフル常時点灯 / フリッカー / スター / ウェーブ / リアクション` の公式全 11 エフェクト＋輝度 1〜4 段階に対応（公式仕様の `RGB` 色順を既定とし、`RBG` 切替も可能）。
  - **起動中のゲーム・アプリごとにプロファイルを自動切替し、連動してマウスの LED 色や DPI も自動で切り替え** られます。

## 対応デバイスの確認方法

デバイスマネージャーまたは HID 情報で以下と一致する個体が対象です。

| 項目 | 値 |
| --- | --- |
| 製品名 | Ray Pawn+（`RM-3360LR`） |
| USB 製品文字列 | `SINOWEALTH` / `Wired Gaming Mouse` |
| Vendor ID / Product ID | `VID_258A` / `PID_1007` |
| ファームウェア ID | `GM07` |
| センサー | PixArt PMW3360（最大 12,000 DPI） |
| 物理ボタン数 | 9（左・右・中・左サイド×2・右サイド×2・DPI+・DPI-） |

※ 同じ SinoWealth 製でも別 PID のマウス（例: `PID_0051` 等）は誤書込み防止のため自動除外しています。

## 使い方（最短セットアップ）

1. MouseButtonMapper を起動し、上部の **「マウス設定・プラグイン」** タブを開きます。
2. Ray Pawn+ が自動検出され、現在のファームウェア・DPI・ボタン配置が表示されます。
   - **初回読み込み時に工場出荷状態の Flash バックアップが自動保存されます**（`%LOCALAPPDATA%\MouseButtonMapper\backups\sinowealth_258a_1007_GM07_initial.json`）。いつでも「初期バックアップから復元」で元に戻せます。
3. **「MouseButtonMapper 連携ワンクリック最適化」** で以下のいずれかを押します：
   - **右サイド 2 ボタンを F13 / F18 に最適化（推奨）**: DPI± はマウス本体機能のまま残し、右サイドの PageUp/PageDown 誤爆を解消します。
   - **右サイド(F13/F18) ＋ DPI±(F19/F20) 全 9 ボタン化**: 上部 DPI± も含めて拡張 4 ボタンすべてを MouseButtonMapper で自由割り当てにします。
4. 必要に応じて DPI・ポーリングレート（おすすめ: **1600 DPI 1 段階固定 / 1000 Hz / 単色点灯**）を設定して「マウスへ書き込む」を押します。
   - ※ PMW3360 センサーは 2,000 DPI 以下でハードウェアスムージングが無効（低遅延）になるため、800〜1600 DPI 付近＋1000 Hz が最も安定します。
5. **「割り当て」** タブに戻り、追加したルールで `右サイド1 / 右サイド2 / DPI+ボタン / DPI-ボタン` を記録またはクリックして好きなショートカットを割り当てます。

## 重要: なぜ `F13 / F18 / F19 / F20` を使うのか？（Windows 11 の `Win + F16` 罠）

拡張ファンクションキー（`F13〜F24`）の一部は、**Windows 10 / 11 が隠しシステムショートカットとして予約**しています。特に以下は `Win` キーを出力するショートカット（例: `Win + H` の音声入力や `Win + V` のクリップボード履歴）と組み合わせた際に誤爆する危険があります：

- **`Win + F16`**: `SlideToShutDown.exe`（「スライドして PC をシャットダウンします」画面）が起動する
- **`Win + F14 / F15 / F21 / F22 / F24`**: Windows のスクリーンショット・設定・プロジェクション等に予約済み

MouseButtonMapper のワンクリック最適化では、Windows 11 の全 16 修飾キー組み合わせで予約衝突がない **`F13 / F18 / F19 / F20`** を既定に採用しているため、安心して `Win + H` や `Win + V` などを割り当てられます。

## 安全性への配慮（Flash 破壊対策）

SinoWealth 系マウスは通信手順を誤るとオンボード Flash の設定ブロックが破損する既知の注意点（`libratbag` 等で報告済み）があるため、プラグイン側で以下の安全装置を実装しています。

- **初回自動バックアップ**: 書き込み前に必ず元の `0x11`（設定）と `0x12`（ボタン）を JSON 保存。
- **2 回連続一致読み取り（Read-Modify-Write）**: 520 バイトの Feature Report を連続 2 回読み出して一致を確認してから、変更箇所だけを最小限に書き換え。センサー種別バイトや後半の LED テーブルは変更しません。
- **書き込み後 450ms 以上のウェイトと読み戻し検証**: Flash 書込み直後の連続アクセスを禁止し、書込み後に必ず読み戻して一致確認します。

## 開発者・Linux ユーザー向け USB HID プロトコル覚書（GM07 / 258A:1007）

公式ソフト消失後に他ツール（`libratbag` / OpenRGB / 自作ツール等）へ対応したい方向けに、実機で検証済みの要点も残しておきます。

- **HID コレクション（Windows）**:
  - `UsagePage 0xFF00` / `FeatureReportByteLength = 6`（`COL05`）: Report ID `0x05` コマンド送受信
  - `UsagePage 0xFF00` / `FeatureReportByteLength = 520`（`COL03`）: Report ID `0x04` 設定・ボタンデータ本体
- **コマンド一覧（Report ID `0x05`）**:
  - `0x01`: ファームウェア文字列取得（`GM07`）
  - `0x02`: アクティブプロファイル番号取得
  - `0x11`: プロファイル 1 設定ブロック読出し（有効長 123 バイト / 書込み時 `buf[0x03] = 0x73`）
  - `0x12`: プロファイル 1 ボタンブロック読出し（有効長 88 バイト / 書込み時 `buf[0x03] = 0x50`）
- **主要オフセット（`0x11` 設定ブロック）**:
  - `0x09`: センサー種別（`0x06` = PMW3360、**書換え厳禁**）
  - `0x0A`: ポーリングレート（下位ニブル `1=125Hz, 2=250Hz, 3=500Hz, 4=1000Hz`）
  - `0x0B`: アクティブ DPI 順番（上位ニブル 1-based）｜有効 DPI スロット数（下位ニブル）
  - `0x0C`: 無効化 DPI ビットマスク（`0` = 有効、`1` = 無効。スロット 1 のみ有効なら `0xFE`）
  - `0x0D..0x14`: 各 DPI スロット値（`(DPI / 100) - 1`、1600 DPI = `0x0F`、12000 DPI = `0x77`、24000 DPI 補間 = `0x78`）
  - `0x1D..0x34`: 各 DPI スロットの色（標準 `RGB` 3 バイト × 8 スロット）
  - `0x35`: LED エフェクト（上位ニブル `0x20` は保持必須、下位ニブル `0=OFF, 1=Colorful Streaming, 2=単色点灯, 3=ブリージング, 4=Tail, 5=Neon, 6=Colorful Steady, 7=Flicker, 8=Stars Twinkle, 9=Wave, 10=Reaction`）
  - `0x38`: 単色モード輝度（上位ニブル `1..4`、最大 `0x40`）
  - `0x39..0x3B`: 単色モード LED 色（3 バイト）
- **ボタン構造（`0x12` ブロック、`0x08` から 4 バイト × 9 スロット）**:
  - 0: 左 / 1: 右 / 2: 中 / 3: 左サイド X1 / 4: 左サイド X2 / 5: DPI+ / 6: DPI- / 7: 右サイド上 / 8: 右サイド下
  - キーボード割り当て: `[0x21, modMask, hidUsage, 0x00]`（例: `F13 = 0x68`, `F18 = 0x6D`, `F19 = 0x6E`, `F20 = 0x6F`）
  - Flash 書込み後は **最低 450ms 待機** すること（連続書込みすると別ブロックが上書き破損する恐れあり）。
