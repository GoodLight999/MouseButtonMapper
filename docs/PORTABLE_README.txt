MouseButtonMapper 8.4.0-rc4 portable

1. MouseButtonMapper.exe を任意のフォルダーから起動してください。
2. 設定は %LOCALAPPDATA%\MouseButtonMapper\config.json に保存されます。
3. ゲームコントローラー機能は実験機能のため、初期状態では設定UIごと非表示・OFFです。
4. 試す場合だけ「動作状態と管理」の小さな「実験機能を表示」を押してください。
5. 不要になったら「機能を停止して設定画面から隠す」でworkerを停止し、専用UIを消せます。
6. 互換Joy-ConはSteamを完全終了し、全HID interface一覧から対象を明示登録します。
   キーボードやマウス等を誤選択しないよう製品名・VID/PID・serialを確認してください。
7. BetterJoyやJoyToKeyへ処理を任せる場合は非表示・OFFのまま使用できます。
8. 緊急停止は Ctrl + Alt + Shift + F12 です。

これはDraft PR #5の実機検証用Release Candidateであり、安定版ではありません。
